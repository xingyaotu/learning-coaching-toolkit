# SOP_CO2 每日伴读流程

## Use when
- 每次伴读开始前和结束后
- 教练需要标准化每日流程保证服务质量
- 监督学员按计划执行学习任务

## 核心目标
每次伴读形成完整闭环：状态调整 → 任务确认 → 执行监督 → 成果确认 → 家长反馈。

## 四阶段操作流程

### 阶段 A：开场（来到自习室）
1. 确认全体学员到位，关注每位学员身体或精神状态
2. 先调整学员状态：简短聊昨天自习和今天在校学习情况（放松，不宜过长）
3. 了解学校作业情况、近期考试安排，协调今日学习规划任务
4. 制定本次伴读任务计划及预估耗时，让学员心中有数
5. 必要时引导学员明确今日目标：「你今天想在哪些方面做出提升？」写出来并贴到前面，按需签字确认

### 阶段 B：任务执行
- 布置任务时说清：学习方式、流程、注意事项、时间限制、考核方法与标准
- 每个任务必须有可量化考核，禁止布置无考核的任务
- 禁止频繁打断学员执行过程
- 持续观察每位学员进度：任务 1/3 处提醒一次，2/3 处再次跟进
- 发现异常（停顿过久、走神、情绪波动）：立即叫停并给出行为方案
- 禁止长时间离开学员视线

### 阶段 C：结束（任务完成后）
1. 再次与学员确认今天学到的知识，检查背诵任务
2. 引导学员复盘：今天有什么收获或遗憾，明天想在哪里有进展
3. 对执行过程中好的行为进行正向确认强化（具体描述，非空洞夸奖）
4. 按重要程度一次纠正 1-2 个问题（避免打击）
5. 给学员信任与期待：「期待你的进步，我会一直陪伴」

### 阶段 D：家长反馈
1. 及时与家长沟通，逻辑明确，拍照佐证学习成果
2. 告知作业任务，定时检查完成情况
3. 如发现需特别纠正的习惯/认知/行为：说明情况 → 提出解决方案 → 承诺跟踪
4. 填写伴读情况记录：学习内容、学习行为、完成情况、评价

## 关键约束
- 禁止不按时填写伴读情况表
- 禁止任由学员提前下课
- 发现异常状态须及时通知负责人及家长
