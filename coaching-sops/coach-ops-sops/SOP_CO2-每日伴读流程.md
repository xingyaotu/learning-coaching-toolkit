# SOP_CO2 每日伴读流程

> 道层合规: 七阶全覆盖 1-7 | 六飞轮滚动 | 八步⑤=流程

## 适用场景

- 每个教练工作日的标准伴读执行流程
- 适用七阶 1-7 全阶段学员

## 执行步骤（4 阶段）

### 阶段 A：晨间准备（08:00-08:30）

1. 读取当日待跟进学员列表（xyt-hq 派发）
2. 查看每名学员昨日任务完成率与七阶当前位置
3. 确认今日六飞轮推进重点（哪个飞轮当前激活）
4. 准备个性化问候语（含正向强化公式）

### 阶段 B：主动触达（08:30-12:00）

1. 按优先级（七阶 1-2 > 3-5 > 6-7）逐一触达学员
2. 使用 SOP_CO4 沟通情绪处理规范响应异常
3. 任务布置参照 SOP_CO3 任务执行流程
4. 所有交互记录推送 Hermes Agent 存档

### 阶段 C：任务跟进（14:00-18:00）

1. 检查上午布置任务的完成情况
2. 未完成任务启动 SOP_CO3 异常处理流程
3. 对完成任务进行八步批改反馈（SOP_06-批改.md）
4. 更新学员七阶位置（若有晋级触发 Hermes 通知家长）

### 阶段 D：日终复盘（18:00-19:00）

1. 汇总当日各学员 MECE 四象限变动
2. 填写日报（completed_tasks / pending_tasks / escalations）
3. 更新 STATUS.md `[DAILY-CLOSE]` 条目
4. 推送明日计划至 xyt-coach 端

## 道层合规检查

- 八步⑤=流程（阶段 B 引用 SOP_CO3 任务流程）✅
- 六飞轮完整覆盖：每阶段均关联对应飞轮 ✅
- MECE 四象限追踪（阶段 D 汇总）✅
