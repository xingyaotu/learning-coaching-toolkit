# SOP_CO3 任务执行流程

## Use when
- 布置学、背、练、预习、复习、诵读、统计、收集、研究等各类伴读任务
- 任务执行过程中出现进度异常、抗拒、拖延等情况
- 任务完成后进行成果检验和行为强化

## 核心目标
每个任务做到：布置清晰 → 过程有监督 → 结果有考核 → 行为有强化。

## 提供任务：五步

### 步骤 1：建立需求感
先给出任务存在的意义，让学员体验自身对这方面有需求

### 步骤 2：明确要求
说明任务在知识和学能两方面的要求：
- 怎样学、流程是什么、注意什么
- 重点背下来什么、达到什么程度
- 时间限制、考核方法、考核标准、考核预期

### 步骤 3：引导预期（针对不成熟学员）
- 询问学员对任务的期待及可能遇到的问题
- 给出正反例：优秀学员会做到什么程度，反之会怎样

### 步骤 4：给信任与承诺
「给信任，给期待，承诺陪伴」

### 步骤 5：开始执行
进入执行阶段，过程中控制打断频率

## 结束任务：六步

1. **记录而非频繁纠正**：执行过程中记录问题，完成后统一处理
2. **正向确认**：对做得好的地方进行具体描述性强化（非空洞夸奖）
3. **针对性纠正**：按重要程度一次纠正 1-2 个，提供纠正方式：
   - 引导观察 → 找到错因 → 归因后矫正 → 正反例对照 → 尝试 → 点评 → 角色扮演
4. **鼓励尝试**：鼓励勇敢尝试，放下包袱
5. **纠正后要求**：对后续学习提出相关行为要求
6. **引导内化**：「学到了什么（知识）？体会到了什么（学习体验）？」

## 常见异常处理

| 情况 | 处理方式 |
|---|---|
| 学员说「任务量太大做不完」 | 先核实是否属实；属实则分批布置；不属实则陪学员先做 5 分钟 |
| 学员拒绝做「不会考的题」 | 核实是否真的不考；确定不考则换题；可能会考则耐心举实例说明意义 |
| 学员明确不想做某任务 | 了解背后原因（6 类）并针对性处理：① 知识不会→回基础 ② 不会用→应用训练 ③ 思路乱→引导梳理 ④ 懒→适当压力+正面肯定 ⑤ 读不懂→调难度 ⑥ 怕错→大量鼓励建信心 |
| 学员偷看答案 | 核实后冷静沟通：认可动机(出发点是好的)→隔开题目和答案→说明任务意义→承诺陪伴→鼓励尝试；禁止给学员贴标签 |
| 学员做完任务太快 | 检查对不对 + 完善得好不好；如确实又对又好，认可努力后商量后续内容；提醒教练要有游刃有余的计划储备 |
| 学员磨蹭拖拉 | 了解原因：不熟练→提供必要帮助；容易走神→引导自我观察（正向角度）；疲倦→有效调整状态 |
| 任务完成质量很差 | 冷静沟通：态度问题→引领调整；知识/题目问题→重新确认学习过程和方法，时间允许则补全未完成步骤 |
