# SOP_CO3 任务执行流程

> 道层合规: 七阶全覆盖 | 八步⑤=流程（核心步骤） | 六飞轮：作业/复习飞轮

## 适用场景

- 教练向学员布置并跟进学习任务
- 适用六飞轮中：作业飞轮、复习飞轮、预习飞轮

## A：任务布置流程（5 步）

### 步骤 A1：任务匹配（八步①穿透 + ②提取）

1. 根据学员七阶位置选取对应难度任务
2. 运行 assessment-toolkit 确认前置知识掌握
3. 输出任务描述：目标阶段 / 知识点 / 预估时长

### 步骤 A2：任务整理（八步③整理）

1. 将任务拆解为 3-5 个子任务
2. 每个子任务标注对应八步编号（①~⑧）
3. 确保⑤=流程子任务有清晰步骤描述

### 步骤 A3：任务审核（八步④审题）

1. 确认任务无歧义
2. 检查任务难度与学员当前七阶匹配
3. 教练签署任务单

### 步骤 A4：任务发布（八步⑤流程）

1. 通过 xyt-student 端推送任务
2. 设定截止时间（默认 24h）
3. 发送开始提醒（正向强化：FIRE-UP）

### 步骤 A5：任务确认

1. 等待学员回执（已读 + 已理解）
2. 未回执超 2h → 触发 SOP_CO4 沟通流程
3. 记录任务 ID 入 STATUS.md

## B：任务完成处理（6 步）

1. 收到学员提交
2. 按 SOP_06-批改.md 运行八步批改
3. 输出批改报告（得分 + 错误分析）
4. 更新七阶位置（SOP_07-分析.md + SOP_08-估分.md）
5. 正向反馈（FIRE-UP 六维强化）
6. 触发下一任务布置（循环 A1）

## C：异常处理（7 种场景）

| 场景 | 触发条件 | 处理动作 |
|------|---------|--------|
| E1 超时未交 | 截止后 2h 未提交 | SOP_CO4 沟通 + 延期处理 |
| E2 质量过低 | 完成率 < 30% | 降难度重新布置 A1 |
| E3 情绪抵触 | 学员表达负面情绪 | SOP_CO4 情绪处理优先 |
| E4 技术故障 | 平台无法访问 | 备用方案 + 延期 |
| E5 七阶误判 | 任务明显超出能力 | 重新 assessment + A1 |
| E6 家长干预 | 家长要求调整 | SOP_CO1 重规划 |
| E7 连续失败 | 3 次未完成 | 上报 xyt-hq + CSO 评估 |
