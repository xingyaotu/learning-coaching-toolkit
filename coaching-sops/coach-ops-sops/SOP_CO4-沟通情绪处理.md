# SOP_CO4 沟通情绪处理

> 道层合规: 七阶全覆盖 | FIRE-UP 六维 | 六飞轮：计划飞轮（情绪稳定是执行前提）

## 适用场景

- 学员出现情绪抵触、沟通障碍、负面反馈
- 家长沟通紧张或投诉情形
- SOP_CO3 异常场景 E3 触发

## A：问题诊断（5 步）

### 步骤 1：识别情绪类型

| 情绪类型 | 信号 | 优先级 |
|---------|------|------|
| 焦虑 | "太难了" "不会" | 高 |
| 抵触 | "不想做" "没意义" | 高 |
| 挫败 | "我很差" "放弃" | 极高 |
| 疲惫 | "太累" "休息" | 中 |
| 正常不满 | "有点烦" | 低 |

### 步骤 2：倾听与确认（八步①穿透）

1. 复述学员感受（不评价、不建议）
2. 确认："我理解你现在感到[情绪类型]，是这样吗？"
3. 等待学员确认

### 步骤 3：MECE 四象限分析

1. M-动力：目标是否仍然认同？
2. E-执行力：当前精力/时间是否充足？
3. C-能力：任务是否超出七阶匹配范围？
4. E-环境：学习环境是否有干扰？

### 步骤 4：调整策略

根据 MECE 分析结果选择对应动作：
- M 不足 → FIRE-UP 激励公式
- E 不足 → 任务量减半 + 时间重排
- C 不足 → SOP_CO3 降难度重布置
- E(环境) 不足 → 协助调整学习环境

### 步骤 5：正向强化收尾

使用正向强化公式（FIRE-UP）：

```
F(Family):   "你的家人为你的努力感到骄傲"
I(Individual): "你比上周进步了[具体数据]"
R(Resources):  "我们有[工具/方法]来帮助你"
E(Ecosystem):  "你的同学也在这样做"
U(Usability):  "这个方法很简单，你可以的"
P(Pathways):   "完成这个，下一步是[里程碑]"
```

## B：情绪处理流程

1. 启用情绪缓冲期（暂停学习任务 30min）
2. 执行 A 诊断流程
3. 记录情绪事件入学员档案（MECE 维度标注）
4. 若挫败情绪极高 → 立即通知家长 + 上报 xyt-hq
5. 情绪稳定后恢复 SOP_CO3 任务流程

## C：家长沟通规范

1. 所有家长沟通在 xyt-parent 端留档
2. 不主动分享学员负面情绪细节（PIPL 合规）
3. 家长投诉 → 24h 内书面回复 → 上报 xyt-hq

## 道层合规检查

- MECE=M-动力/E-执行力/C-能力/E-环境（步骤 3 明确）✅
- FIRE-UP 六维（步骤 5 完整列出）✅
- 六飞轮：计划飞轮（情绪稳定是执行前提）✅
- 八步①穿透（步骤 2）✅
