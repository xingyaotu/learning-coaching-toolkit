# SOP_CO4 沟通与情绪处理

## Use when
- 学员提问、情绪激动或与教练形成对抗
- 需要正面强化学员好的行为
- 处理沟通中的个性化特点或抗拒情绪

## 核心目标
「多听少说，把话语权交给学员。观察状态 → 了解动机 → 思考方式 → 引导正向。」

## 回答问题：五步诊断流程

1. **判断题目与答案**：先确认题目和答案是否正确，是否匹配学员现有能力
2. **读题圈词**：让学员平静地把题目再读两遍，圈出关键词（能解决一部分问题）
3. **定位不会的环节**：询问哪个环节不会，按参考答案步骤逐句核查
4. **确定问题性质**：
   - 知识不扎实？→ 回到知识点
   - 流程不清晰？→ 梳理解题流程（对接 SOP_05-流程）
   - 某步骤不理解？→ 引导思考理解
   - 细节没做到位？→ 具体强化该细节
5. **验证学习效果**：时间允许时再次让学员确认本次学习关注点并检验效果

## 情绪处理：先处理心情，再处理事情

### 学员情绪激动/对抗时：
1. **教练保持冷静**，专业面对，不与学员比谁对谁错
2. **倾听动机与诉求**：观察并理解情绪激动的根本原因
3. **共情与描述**：专业进入共情环节，描述学员感受（「我注意到你现在...」）
4. **提出共同方式**：给出其他观察角度，引领看到更多可能，提供更温和达成诉求的方式
5. **恢复后给台阶**：情绪平静后不要让气氛尴尬；必要时暂时搁置，间隔后再处理

### 禁止行为
- 禁止长辈式/家长式/教导式语言教训学员
- 禁止说「这很简单啊」「这你都不会」
- 禁止拿学员行为开玩笑或表示不屑
- 禁止对学员进行语言攻击或人身攻击
- 禁止用「敢不敢」「要不要」「信不信」等对抗语言
- 禁止给学员贴标签或定性

## 正面强化：描述性夸奖公式

不要说：「你好棒！你太优秀了！」

要说（描述性强化四步）：
1. 描述**看到的行为经过**（体现教练关注）
2. 说明**达成了什么效果**
3. 表达**对学员和教练的感受和影响**
4. 赋予**意义**：让学员感受到自己被需要、有价值

## 个性化特点处理

- 若家长和学员均非常抵触改变：暂时接纳包容，不强行纠正
- 观察行为产生原因，保护学员自尊心
- 在行为发生后做干预：把注意力引导到学习探索和自我观察

## 时间把控

- 提前告知任务时间限制，观察过程中不要慌张或节奏太快
- 任务 1/3 处提醒，2/3 处再次跟进
- 走神时：引导学员观察自己如何从走神**回归专注**（正向角度），而不是观察如何走神
- 禁止长时间离开学员视线

## 核心原则

> **赢得学员，不是赢了学员。**  
> 温柔且坚定，友善并守规矩。  
> 有效陪伴：持续关注行为与情绪 → 了解内心需求 → 结合学习引领注意力 → 强化学习行为 → 形成稳定模式。
